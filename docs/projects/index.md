## 🔥 项目列表

### 🤖 机器学习项目

#### 垃圾分类图像分类模型
[![GitHub](https://img.shields.io/badge/GitHub-查看代码-blue)](https://github.com/G1234-cod/garbage-classification-model)

**项目简介**：基于深度学习的垃圾分类图像分类系统

**技术栈**：
- Python / PyTorch
- ResNet / MobileNet / EfficientNet
- 数据增强与模型优化

**核心功能**：
- 支持多种垃圾分类（可回收物、有害垃圾、湿垃圾、干垃圾）
- 端到端训练与推理流程
- 模型性能对比分析

**项目结构**：
```
garbage-classification-model/
├── model.py          # 模型定义
├── train.py          # 训练脚本
├── predict.py        # 推理脚本
├── config.py         # 配置文件
├── data_loader.py    # 数据加载
├── analysis_results/ # 分析结果
└── test_image/       # 测试图片
```
